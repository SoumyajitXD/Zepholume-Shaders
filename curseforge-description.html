01  /  The experience

More feeling in every familiar block.

Zepholume builds atmosphere through deliberate adjustments to the light, colour and environment already in Minecraft. The result aims to feel cohesive across exploration, building and survival—without swapping in an oversized effects pipeline.

01   Living atmosphere

Skies, horizons and fog respond together as daylight gives way to twilight, night and changing weather.

02   Grounded lighting

Directional sun and moon response, restrained ambient treatment and block-light warmth are designed to respect the scene.

03   Water with character

Profile-scaled water shading, subtle surface movement on Balanced and above, and restrained underwater atmosphere.

04   Controlled colour

Carefully bounded contrast, exposure, saturation and highlight treatment aim for depth without overwhelming Minecraft's identity.

03  /  Choose your balance

Five profiles. One philosophy.

Every profile works within Zepholume's direct-path architecture. Lower tiers leave optional work out; higher tiers refine the same approach instead of replacing it with a heavier renderer.

Recommended starting point  •  Default

BALANCED

The intended everyday experience: atmospheric colour, material response, enhanced depth and gentle two-wave water movement. Start here, then adjust for your hardware.

POTATO

The minimal-work tier for weaker hardware or troubleshooting. Optional analytical effects are compiled out.

LOW

Lightweight atmospheric, cloud, weather and water treatment without animated water movement.

HIGH

More nuanced ambient, cloud and water response for systems with greater graphics headroom.

ULTRA

Zepholume's fullest available analytical detail, still within the same deliberately restrained rendering design.

The five profiles are defined in V1.0.5; the Potato option's visibility in the live loader menu has not yet been verified. See the full profile guide.

04  /  The current release

V1.0.5 — Refine the light.

This release concentrates on lighting correctness and shader configuration while keeping the existing lightweight renderer.

  • Lightmap fixes: restores missing lightmap application on affected lit scene paths to address source-level causes of full-bright caves and interiors.
  • More deliberate colour: revises skylight handling, low-light values and highlight processing in response to harsh contrast and lost dark detail.
  • Cleaner settings: repairs Iris shader-option tooltip keys and maintains five defined quality profiles.
  • Broader static testing: the Phase 10 local checks reported 272 GLSL stage validations, 420 shader-link checks and 630 mocked portability cases.

Development transparency

These corrections have source-level and static validation, but V1.0.5 has not completed qualifying in-game Iris/Oculus visual checks. Brightness, contrast and the Potato menu remain subject to runtime verification. No measured FPS gain is claimed.

05  /  Performance by design

Less machinery. More Minecraft.

A visually ambitious pack does not need an endless chain of render passes. Zepholume uses a GLSL 330 direct-path design, one colour target and compile-time quality boundaries to keep the architecture understandable and the work bounded.

Deliberately not included

Shadow-map pipelines  •  Screen-space reflections  •  SSAO  •  Bloom pipelines  •  Temporal/TAA systems  •  Volumetric lighting  •  Ray tracing  •  Heavy post-processing chains

Efficient design is a goal, not an FPS guarantee. Actual results depend on GPU, drivers, resolution, settings and mod combinations; controlled V1.0.5 gameplay benchmarks remain outstanding. Read the architecture overview.

06  /  Get started

From download to daylight.

Installation

  1. Set up Minecraft Java Edition with a compatible Iris or Oculus shader loader.
  2. Download Zepholume-Shaders-1.0.5.zip from the Files page.
  3. Place the ZIP in that instance's shaderpacks folder. Do not extract it.
  4. Choose Zepholume in the shader menu, then select Balanced.

Full installation guide

Compatibility

Zepholume targets Iris and Oculus-style shader environments. The most thoroughly staged V1.0.5 setup is Minecraft 1.20.1 with Iris/Fabric or Oculus/Forge; even these have not completed final launch-and-render qualification.

Minecraft 26.2 has static or experimental target lanes; versions such as 26.3 may be listed in file metadata without a completed runtime test. OptiFine is not a tested or supported target.
