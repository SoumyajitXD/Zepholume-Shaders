# V1.0.7 Phase 1 water, materials and cost audit

Date: 2026-10-29. Development worktree: `C:\MinecraftJavaMods\Zepholume Shaders\_v107-phase1`. Baseline: local V1.0.6 source at `50de98824c1100b3e305e9030aad91de7e285fa7`, with inherited tooling checkpoint `3d92f57`. This report covers source mathematics and standalone native GLSL, not Minecraft rendering or performance.

## Confirmed defect and correction

The V1.0.6 `zephWaterSurfaceLinear` uses sun/moon world elevation to bound celestial availability and then a Blinn half-vector lobe. It does not check the local incident-light cosine. An above-world-horizon light can therefore illuminate a vertical water facet facing away from it; a half-vector alone does not establish that light reaches that side of the facet. It can also produce a highlight for a view on the back side of the supplied normal.

Before changing production GLSL, the retained actual baseline library was compiled into a one-pixel RGBA32F fixture on Intel UHD Graphics 730, driver `32.0.101.7085`, OpenGL/GLSL 4.6. Black albedo and black sky isolate the celestial term. Across 435 draws / 15 programs (five water tiers, three dimensions), 46 samples disagreed with an independent corrected local-incidence reference. The baseline GLSL agreed with the independent original-algorithm reference within `6.191996032578473e-7`. Thus the diagnosis does not depend solely on a source-text assertion or an assumed screenshot cause.

`shaders/lib/water.glsl` now multiplies each celestial lobe by `max(dot(normal, lightDir), 0)`. The half-vector/lobe block is skipped when that cosine or the already-computed `NdotV` is zero. Multiplying the incident cosine makes the contribution approach zero continuously as a light crosses the local facet horizon; a binary incident-light gate alone would create a jump. At normal incidence the former maximum is preserved. Tilted illuminated surfaces intentionally receive weaker highlights. No albedo, sky reflectance, wave coefficient, material ID, alpha rule, grading parameter or new rendering pass changes.

The corrected actual source passed all 435 native draws / 15 programs, maximum corrected CPU-reference error `5.064943240373765e-7`, zero corrected-reference mismatches. Both independently injected GLSL regressions were rejected: replacing local incidence with one produced error `0.06928047523287995`; removing only the view-side gate produced `0.0027980112936347723`. These are native library-isolation fixtures, not loader-transformed shader execution, fluid mesh tests, blending tests or gameplay screenshots.

## Preserved baseline and limitations

- The prior fragment-local distance and raw view-ray interpolation repair is already present. Fresh baseline and post-change CPU runs pass 450 perspective/interpolation cases; it was not reapplied.
- Root plus three dimension hand wrappers already consume the lightmap. Fresh pre-change source check passed four routes and rejected eight missing/late-flag controls. The new water change does not alter this routing.
- The existing uniform exact-zero specular gate remains. Fresh pre/post runs pass 1,440 float32 predicate cases / 1,680 zero lobes, error zero. That test proves only its original uniform-weight equivalence, not the new visual correctness contract.
- Glass, ice and other non-water translucent terrain continue through the ordinary scene route. Material 10001 remains the only analytical-water classifier.
- **Unresolved architecture limitation:** analytical environment reflection/highlights lack local directional skylight visibility. The new local-incidence check fixes facet-side illumination, not roofs, caves or terrain occlusion. Propagated ambient skylight is not directional visibility; block light must not enable sky reflection. No arbitrary skylight attenuation is introduced without matched gameplay evidence.
- Two-sided underwater interface orientation, actual water mesh normals, waterfall appearance, transparency sorting, night/cave balance, and modded dimensions remain **NOT TESTED in Minecraft**. No actual AMD/NVIDIA driver execution occurred.
