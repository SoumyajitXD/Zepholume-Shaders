# V1.0.8 source and validation

V1.0.8 was finalized on November 25, 2026. See the [changelog](../CHANGELOG.md#108--finalized-for-local-export-2026-11-25) for rendering changes and the [known issues](KNOWN_ISSUES.md) for runtime gaps.

## Rebuild the finalized shader pack

From `Zepholume-Shaders/` in a clean Git checkout, run PowerShell 7.

```powershell
./scripts/package.ps1 -OutputDirectory ./dist
Get-FileHash -Algorithm SHA256 -LiteralPath ./dist/Zepholume-Shaders-1.0.8.zip
```

The final ZIP SHA-256 is `A4C733D2ACB89A7BCBD158A40BF19B114D02B8A357AA9EFA7E97AC1262E0D804`. The ZIP contains 134 shader files, the pack README, changelog, third-party notices, and the repository license and notice. It contains no development scripts or benchmark data. The packager uses ordinal entry ordering, a fixed timestamp, and the release's CRLF line endings for the license and notice entries. Compression can vary across environments. To verify entry names and SHA-256 hashes individually, compare archives with `python scripts/ci/compare_packages.py <final.zip> <rebuild.zip> <report.json>`.

## Compatibility and performance evidence

The development target range is Minecraft Java Edition 1.20–26.3, with Iris as the primary loader and an Oculus compatibility path. The source defines Potato, Low, Balanced, High, and Ultra in the Overworld, Nether, and End. The unmodified settings use Balanced. The pack writes a single colour target.

Release qualification exercised standalone loader patchers for Iris 1.7.6 on 1.20.1, Oculus 1.8.0 on 1.20.1, Iris 1.10.7 on 1.21.11, and Iris 1.10.9 (JAR labelled 26.1.1) using a Fabric 26.1.2 fixture instance. The opt-in Windows fixture in `scripts/tests/loader-transform-probe.py` invokes those patchers in a standalone JVM with pre-expanded shaders and fixture geometry. Full loader preprocessing and in-game rendering require a Minecraft run.

Use the [benchmark protocol](BENCHMARK_PROTOCOL.md) for Minecraft gameplay measurements. Offscreen GPU timings from shader fixtures and deterministic analyzer tests provide synthetic evidence only. The finalized V1.0.8 ZIP has no Minecraft gameplay or visual qualification.
