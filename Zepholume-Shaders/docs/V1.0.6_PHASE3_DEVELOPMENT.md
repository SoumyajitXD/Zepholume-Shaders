## Source changes and reasoning

1. **Exact valid fog ranges.** Phase 2's immersed branch used `max(fogEnd - fogStart, 0.0001)`. For valid `fogStart=0`, `fogEnd=0.000001`, its factor at `fogEnd` was only `0.01` before the water tier multiplier. Open-air atmosphere and cloud fog also clamped `fogStart` to at least 1 and the range to at least 1; for valid 0–0.5 input, both stayed at zero through the actual endpoint. `fog.glsl`, `atmosphere.glsl`, and `cloud_fragment.glsl` now divide by the exact **positive** loader range. Equal or reversed ranges use a defined step at `fogStart`, avoiding division by zero and leaving valid ranges untouched. The existing atmospheric Hermite/horizon/weather shaping and cloud rain factor remain. A clear, horizontal Balanced open-air factor at its 0.5 endpoint is 0.84 by design, not full fog; the correction restores the distance term, not a new artistic endpoint policy.
2. **Water lobe weight reuse.** `water.glsl` already computed uniform-only `sunWeight = daylight * sunHorizonFade` and `moonWeight = (1.0 - daylight) * moonHorizonFade` for exact-zero gates. The active lobe bodies redundantly multiplied those same factors again. They now multiply the lobe by the existing weight. This is algebraically exact over real numbers and has at most `1.49e-8` float32 difference over the tested boundary/grid cases due to evaluation order. It removes one source multiplication per active lobe; a real driver may already have eliminated it. The prior expression is recoverable from checkpoint `22dfaea`.
3. **Potato cloud gate.** The sun normalization, daylight, weather and tint setup previously preceded `#if ZEPH_EFFECTIVE_CLOUD_QUALITY == 0` even though Potato did not consume it. The setup is now inside the enabled branch. The new evaluated-source check fails if Potato cloud variants contain the analytical names. The final preprocessed Potato cloud stage omits them, while Balanced water stages contain the weight reuse. No visual equation changes for enabled clouds.
4. **Menu accuracy and validator path.** `ZEPH_FOG_QUALITY` is used for cloud fog, while `ZEPH_ATMOSPHERE_QUALITY` controls the scene fog curve. The English label now says “Cloud fog.” The WSL standalone linker initially failed all 420 links when given a relative `-ReportRoot`, because its Windows link-input paths were passed without `/mnt/c` conversion. `validate-glsl.ps1` now resolves that root to an absolute path. The corrected run is recorded below.

The architecture remains GLSL 330 compatibility, one `gl_FragData[0]` colour output, shared libraries, five compile-time profiles with Balanced default, and direct `gbuffers_*` routing. No extra pass or buffer was added. Neither the tiny source-operation reduction nor successful driver compilation measures GPU speed. **Real FPS change: NOT MEASURED.**
