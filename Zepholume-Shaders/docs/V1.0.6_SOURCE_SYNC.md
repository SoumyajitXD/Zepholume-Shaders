# V1.0.6 source synchronization

Date: 2026-10-28 (Asia/Calcutta).

This synchronization publishes the finalized V1.0.6 source under the existing
`Zepholume-Shaders/` subtree. It is based on upstream main
`498f0e52b7cfac293ad0ece294479f66df696c5b`, without merging the development
branch's history or its release archives. The original clean development branch
is `codex/v106-phase8` at `50de98824c1100b3e305e9030aad91de7e285fa7`;
the frozen production source is `9c758a776ca4b6a7d3acd6e8a8b557f9f1fe2e66`.

All 135 packaged files, including all 132 shader-tree files, match the final
archive after CRLF/LF normalization. Its SHA-256 is
`F72C149F44E6EE026025215D27886CD50D73252A4FE046E184DDBBB8E552331C`.
Repository text uses the established Git line-ending rules; a ZIP rebuilt from
this checkout consequently has different raw bytes from the Windows export.
Two builds in the publication checkout were byte-identical and their 135
entries passed the retained CI package-content gate.

## Scope and retained upstream work

The affine view ray and fragment-local distance, all four hand lightmap flags,
camera-space world-up calculations, short fog-range handling, material routing,
alpha and dimension wrappers are preserved. Potato, Low, Balanced, High and
Ultra remain unchanged, with Balanced recommended and matching source defaults.
No rendering algorithm or numeric quality setting was changed during this sync.

Upstream's six `scripts/ci/` files, CI workflows, profile-parser newline fix,
and BOM/newline regression coverage are retained. Local option-validation and
regression additions are combined with those upstream changes. One concrete
tooling correction constructs generated variant paths with `unique/` instead
of doubled Windows separators, so the retained strict CI coverage gate accepts
the generated index on Windows as well as Linux. Tests were not weakened.

Historical development and final-export reports retain their original dates
and statements. In particular, their 'GitHub publication not performed' wording
describes the earlier export operation, not the later source synchronization.
Generated evidence referenced by those reports remains local and is not part
of the source repository.

No existing source file is deleted. Generated artifacts, ZIPs and sidecars,
runtime installations, logs, screenshots, caches and local compatibility
inventory are excluded. Historical preview, runtime-staging and timing scripts
that were not needed for maintained regression entry points are not added.
All paths outside this source subtree, including root documentation, workflows,
licensing, release archives, screenshots and CurseForge HTML, are preserved.
Upstream advanced during validation by adding the final V1.0.6 archive; its
Git blob hash matches the local final ZIP. That upstream addition is retained
unchanged and the synchronization uses the advanced commit as its parent.
