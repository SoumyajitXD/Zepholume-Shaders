## 3. Seven-fixture fog comparison

The preserved Phase 4 dataset `artifacts/phase4-gpu/compare-v105-v106/comparisons.json` has 25 cases, seven changed and 18 unchanged. Its SHA-256 remains `9D4A4FA98CC11E50C0B577FFAA91A5A143F6ACB6513A34604DCB09B10EEBDCF7`. Every changed case uses `fogStart=0`, `fogEnd=0.5`. The V1.0.5 equations force `fogStart >= 1` and `fogEnd >= fogStart+1`; Phase 3 uses the exact positive loader range, with a defined step for equal/reversed endpoints. The seven observed maximum RGBA channel deltas are `0.229891`, `0.206182`, `0.385700`, `0.225961`, `0.117750`, `0.230441`, and `0.228721`; maximum alpha delta is zero in every case. The largest is short underwater near the endpoint.

The original framebuffer is **RGBA32F float**, not normalized 8-bit. Across those GPU results the observed output channel range is `0.0350419–1.0`; `0.385700` is a float channel difference. An independently written reference predicts the Balanced underwater midpoint factor `0.53` and endpoint RGB `(0.1856, 0.2964, 0.3916)`, agreeing with prior center pixels within `2e-4`. The Balanced water multiplier reaches full fog at approximately distance `0.4717` in a 0–0.5 range. There is a slope kink, not a value discontinuity. Equal/reversed ranges produce the specified step at `fogStart`; beyond the endpoint remains fully fogged. Short air, lava, powdered snow, multiple fog colors, near-zero, min/max visibility, and Potato–Ultra profiles received numerical or GPU coverage. The source-locked reference at `scripts/tests/phase6-fog-audit.py` passed 120 cases and rejected an injected wrong midpoint. Its machine result is `artifacts/phase6-fog-audit/reference.json` (SHA-256 `574754EE481C0D09B1C94B7D2800FABCE1D295F11142BFC4F08BE04327455B52`). No additional fog correction was justified.
