# Zepholume Shaders V1.0.6 release notes

Released locally: 2026-10-28. Artifact: `Zepholume-Shaders-1.0.6.zip`.

## Copy-ready changelog

- Restored per-surface lightmap lighting to hands and held objects in every dimension wrapper, preserving existing hand grading and alpha.
- Corrected view-ray and distance interpolation, eliminating reproduced triangle-diagonal water and fog differences in standalone regression fixtures without changing wave geometry.
- Corrected camera-space world-elevation calculations used by lighting, sky, clouds and fog.
- Preserved valid short loader fog ranges and defined safe behavior for equal or reversed fog endpoints.
- Retained Potato, Low, Balanced, High and Ultra, with Balanced recommended by default and the existing lightweight direct rendering path.
- Expanded source-bound compilation, profile, portability, hand, water and deterministic-package verification.

Testing limitation: these are source and offline fixture improvements. Waterfall and hand appearance, loader/version compatibility, transparency composition and FPS have not been qualified in Minecraft for this final artifact. Analytical water reflections still lack local skylight occlusion and may remain visible under cover.

## Installation

Copy the intact final ZIP into the intended Minecraft Java instance's `shaderpacks` directory. Use a matching Iris installation, select Zepholume in the shader menu, and begin with Balanced. Existing shader settings can override source defaults; explicitly choose a profile to apply its complete baseline. The archive has `shaders/` directly at its root and does not need extraction. Oculus uses the retained compatibility path but is not runtime-qualified for this release. OptiFine is unsupported.

## Known limitations

Analytical sky reflection and sun/moon water highlights are added after base lightmapping without a local occlusion input. Sky-light coordinates describe ambient propagation, not directional visibility; a naive global or lightmap multiplier could damage correct open-sky reflections. No speculative brightness correction is included.

The corrected hand path and affine interpolation are verified by source contracts and controlled GPU fixtures. Actual waterfall meshes, empty/opaque/translucent/emissive held items, overlapping transparency, covered/night water, all profile menus, dimensions and loader transformations remain unverified in gameplay. The pack does not add dynamic held-item illumination, shadows, SSR, bloom or new rendering passes.

Historical Phase 8 Intel flat-quad timer measurements (water about 3.1% faster, hand about 2.44% slower; A/A drift below 0.16%) remain synthetic fixture observations. The extra hand lightmap fetch is retained for correctness. These measurements do not establish Minecraft FPS or frame-time changes.
