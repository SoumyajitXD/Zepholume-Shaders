# V1.0.6 Phase 7 tooling and CI audit

## Scope and confirmed corrections

The actual Git root is the parent of this source project. Its workflow is `.github/workflows/ci.yml`, not `shader-validation.yml`. This audit examined the Phase 6 collector, package allow-list and manifest, source/profile validator, variant generator, glslang runner, regression tests, portability worker and current workflow directly.

1. **Windows crash-report redaction:** `GetRelativePath` returned a backslash-separated crash-report name, but `Add-EvidenceFile` classified diagnostic text using forward-slash patterns. An isolated synthetic crash report reproduced the failure before modification. The collector now normalizes relative separators before directory classification and rejection records. `runtime-collector-tests.ps1` passed after the fix, checking both diagnostic directories, preservation of useful shader messages and original files, copied hashes, stale and unexpected-extension rejection, binary preservation and screenshot basename rejection. Fixtures contain no real account data and are deleted from a verified temporary directory. This is collector behavior evidence, not a Minecraft session.
2. **Link warnings:** `-WarningsAsErrors` previously inspected only stage warning counts. The condition now covers stage and program-link warnings while retaining Phase 6's absolute report-root resolution. This is an isolated backport of the upstream condition, not a merge. `glsl-warning-tests.ps1` supplies a fake compiler backend with clean stages and one link warning: advisory mode succeeds; strict mode fails with the intended diagnostic. No installed compiler or game is simulated by this policy fixture.
3. **CI execution:** the existing Windows smoke job now executes both focused fixture suites. The existing Linux regression job runs the independently implemented camera-space regression. Existing read-only permissions, SHA-pinned actions, package manifest validation/upload, and separate runtime evidence requirements remain.
