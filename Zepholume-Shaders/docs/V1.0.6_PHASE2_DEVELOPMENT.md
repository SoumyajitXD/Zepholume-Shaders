## Confirmed source defect and fog validation

Phase 1 fixed the main underwater endpoint defect, previously about 0.730128 at `fogEnd` in a clear vertical Balanced view. A Phase 2 numerical audit found that its new immersed-media branch still forced `mediumStart >= 1.0` and `mediumEnd >= mediumStart + 1.0`. For a valid loader range `fogStart=0`, `fogEnd=0.5`, that branch produces zero fog factor at the actual endpoint. This is a direct source-arithmetic defect. `shaders/lib/fog.glsl` now uses the exact loader start and end difference, guarding only a zero denominator with `0.0001`. The water profile multipliers and loader-owned lava/powder-snow colours remain unchanged.

`scripts/tests/math-regression.ps1` now checks 0–0.5, 0.25–0.75, -0.5–0.5, and 16–64 ranges for water, lava, and powder snow at all five tiers, including starts, midpoints, and endpoints. The source assertion requires the unshifted loader range. This is numerical/source coverage. Actual fog uniforms, viewing angles, colour, haze, surface transitions, lava, and powder snow appearance still require a rendered world. No screenshot-based colour adjustment was made.
