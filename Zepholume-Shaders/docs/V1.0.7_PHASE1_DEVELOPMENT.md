## Parallel work and decisions

Three subagents worked concurrently with the lead, the available useful concurrency. Tooling owned scripts/CI; atmosphere owned fog/cloud GLSL and its fixtures; water owned water GLSL and fixtures, then reviewed performance and specialization. The lead coordinated integration and handled profiles, compatibility, runtime discovery, packaging verification, source review and final checks. The subagents' detailed findings are retained in [tooling](V1.0.7_TOOLING.md), [atmosphere](V1.0.7_ATMOSPHERE.md), [water](V1.0.7_WATER.md) and [performance](V1.0.7_PERFORMANCE.md).

1. **Atmosphere:** the old enabled air fog could stop at 0.6888 in a clear vertical view and cloud fog at 0.76, even beyond `fogEnd`. The endpoint-preserving interior-density curves preserve zero/full endpoints while retaining weather and horizon response. Cloud view position is now interpolated before fragment-local length; scalar corner lengths were nonlinear and produced diagonal differences. This adds interpolation and fragment-length work; it is a correctness tradeoff with no measured speedup.
2. **Water:** celestial Blinn highlights previously lacked local incident-light and view-side checks. Each lobe now uses local incident cosine, smoothly reaching zero at the facet horizon, and skips the lobe for a back-facing view. No texture, uniform, target or pass was added. Four hand lightmap flags and the existing water ray fix are preserved, not reapplied. Directional local sky occlusion remains unavailable; no arbitrary skylight multiplier or claim of accurate roof shadows was introduced.
3. **Reliability:** package ordering now uses ordinal paths, relative destinations follow the PowerShell location, and ZIP/hash/manifest are staged with non-overwriting promotion and cleanup of this invocation's partial outputs. Ten fixture checks pass versus four at baseline. The manifest is a completion marker, not a crash-atomic transaction, and hostile concurrent replacements are outside its guarantees. Validator tests count actual rejected fixtures; the absent optional V1.0.4 ZIP is correctly reported as skipped.
4. **Hosted CI defect:** fresh upstream Windows checkout reproduced the exact three reported dirty benchmark/protocol files before any test. Their committed CRLF/mixed bytes conflict with upstream LF attributes. Linux Git reproduced the same three paths using the upstream attribute rules as a negative control. Three `-text` exceptions preserve the exact tracked bytes; fresh Windows and Linux checkouts of this branch start clean. The original end-of-test clean-tree gate remains, and an initial gate detects checkout problems. The historical hosted run failed; **a new hosted workflow was not run**, and no hosted green status is claimed.
5. **Upstream integration:** imported the current upstream CI workflows, six evidence/coverage helpers, CI qualification documentation and profile-parser LF/CRLF/BOM fix, retaining the additional V1.0.7, output-safety and collector checks. Corrected generated variant paths from a doubled separator to a single forward slash. Existing outputs contain the same 5,040 source hashes after this path-only change.
6. **Performance:** 96 source-bound specialization cases confirm the intended profile/dimension gates. Potato cloud vertex source still computes normal elevation despite the fragment path not using it; a compiler may remove it at link time, so an explicit gate was deferred until equivalence and performance are demonstrated. No game frame times or FPS were measured. No additional speculative optimisation was retained.
