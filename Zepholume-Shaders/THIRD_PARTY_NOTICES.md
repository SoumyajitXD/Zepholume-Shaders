# Third-party notices

Zepholume's GLSL implementation is original and incorporates no code from other shader packs.

The project format follows public Iris/OptiFine shader-pack conventions. No source code was copied from these documents or from the Iris example shader pack; the example was consulted only for layout and loader behaviour.

Runtime-debugging behaviour is documented from Iris public documentation. Oculus is an unofficial Forge-oriented Iris fork; its public repository was consulted for compatibility context only.
# glslangValidator

Development validation may use `glslangValidator.exe` from the official KhronosGroup/glslang GitHub `main-tot` Windows Release asset. The tool is used only to compile Zepholume-preprocessed standalone GLSL in OpenGL mode; it is excluded from release ZIPs. glslang is licensed under Apache-2.0; see the upstream repository for the complete license text.
