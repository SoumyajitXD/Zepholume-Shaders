# Zepholume Shaders

Zepholume Shaders is a Minecraft Java Edition shader pack focused on atmospheric lighting, polished visuals, practical performance, and maintainable shader architecture.

## Status

The project is under active development. Runtime compatibility, supported Minecraft versions, installation instructions, screenshots, and release downloads will be documented after they are verified.

## Principles

- Visual quality without blindly sacrificing performance
- Clear, maintainable shader code
- Compatibility claims backed by actual runtime testing
- Reproducible builds and verified release archives
